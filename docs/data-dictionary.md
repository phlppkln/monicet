# Data dictionary — `public/data/monicet-map-data.json`

This is the only data file the app loads (plus the `azores.geojson`
basemap). It is generated by `scripts/build-data.ts` from `data/raw/`. The
TypeScript shape is in `src/types/monicet.ts`, and both the build and the
app import it.

Key definitions:

- **Cruise** — one whale-watching trip (`event.type = "cruise"`). It is the
  only effort unit available.
- **Sighting event** — one stop with animals (`event.type = "sample"`).
- **Encounter** — one _(sighting event, species)_ pair. Life-stage rows of the
  same species in the same event collapse into one. Only species-rank names
  count; family-only records are dropped. **Every count in the JSON is a
  count of encounters.**
- **Cell** — a 0.2° × 0.2° bin, about 22 km N–S × 17.5 km E–W at 38° N. Its
  origin is `floor(min / 0.2) · 0.2` of the sighting positions. Cells exist
  only where at least one encounter happened.

## `meta`

| Field                          | Meaning                                                              |
| ------------------------------ | -------------------------------------------------------------------- |
| `totalSampleEvents`            | sighting events with a valid date and position                       |
| `totalCruiseEvents`            | rows with `type = "cruise"`                                          |
| `totalOccurrenceRows`          | all rows in `occurrence.txt`                                         |
| `totalUniqueSpeciesEncounters` | encounters, as defined above (30,050)                                |
| `excludedNonSpeciesRows`       | family-level occurrence rows dropped                                 |
| `rowsWithoutMatchingEvent`     | occurrences whose `eventID` is not a sighting                        |
| `years`                        | years that have cruises (2009–2020)                                  |
| `bestMonthOverall`             | month with the highest `encounters / cruises`, pooled over all years |
| `thresholds`                   | constants behind `isReliable`                                        |
| `caveats`                      | free-text caveats; the UI shows only the first                       |

## `gridCells[]`

| Field                                               | How it is computed                                                                             |
| --------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| `id`, `row`, `col`                                  | `"row:col"`, offsets from the grid origin                                                      |
| `lat0`, `lon0`, `centerLat`, `centerLon`, `polygon` | cell geometry (polygon is a closed ring, `[lon, lat]`)                                         |
| `encounterCount`                                    | encounters in the cell, all years                                                              |
| `yearlyEncounters`                                  | `{ "2009": n, … }`, only years with > 0                                                        |
| `monthlyEncounters`                                 | 12 numbers, Jan–Dec, all years pooled                                                          |
| `speciesCounts`                                     | `{ speciesId: n }`                                                                             |
| `earlyRate` / `lateRate`                            | encounters in the early / late half of `years` ÷ **all** cruises in that half (see ISSUES D-1) |
| `declinePct`                                        | `(late − early) / early · 100`; `null` if `earlyRate` is 0                                     |
| `trendSlope`                                        | OLS slope of yearly `encounters / cruises`; computed but **unused**                            |
| `yearsWithEncounters`                               | number of years with > 0 encounters                                                            |
| `confidenceScore`                                   | `min(1, encounterCount / 80) · min(1, yearsWithEncounters / 4)`                                |
| `isReliable`                                        | `encounterCount ≥ 24 && yearsWithEncounters ≥ 3`                                               |
| `topSpecies`                                        | top 3 species by count: `{ speciesId, count, scientificName, commonName }`                     |

## `speciesSummaries[]` (sorted by `totalEncounters` desc)

| Field                                                      | Meaning                                                                             |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| `speciesId`                                                | WoRMS LSID                                                                          |
| `scientificName`, `commonName`                             | the common name comes from a hand-written map; it falls back to the scientific name |
| `totalEncounters`, `yearlyEncounters`, `monthlyEncounters` | as for cells                                                                        |
| `cellCounts`                                               | `{ cellId: n }`                                                                     |

## `monthlySummaries[]` (12 entries)

| Field            | Meaning                                          |
| ---------------- | ------------------------------------------------ |
| `month`, `label` | 1–12, "Jan"…                                     |
| `encounters`     | encounters in this calendar month, all years     |
| `cruises`        | cruises in this calendar month, all years        |
| `rate`           | `encounters / cruises`                           |
| `topSpecies`     | top 5 species, with `share = count / encounters` |

## `speciesLookup`

`{ speciesId: { scientificName, commonName } }` for every species in the
build.

## `bounds`

The extent of the sighting positions, plus the grid origin
(`minLatGrid`, `minLonGrid`).

## Which view uses what

| View                    | Fields                                                                                                                                         |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| D1 Honest Instability   | `declinePct`, `isReliable`, `speciesCounts`, `monthlyEncounters`, `topSpecies`, `monthlySummaries`, `meta.bestMonthOverall`, `meta.caveats[0]` |
| D3 Species as Character | `speciesSummaries`, `speciesCounts`, `topSpecies` (dominance)                                                                                  |
| D4 Field Journal        | `yearsWithEncounters`, `yearlyEncounters`, `speciesCounts`, `confidenceScore`, `isReliable`                                                    |
